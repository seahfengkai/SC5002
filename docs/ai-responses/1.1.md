## Response (verbatim)

**Admissible heuristics in A* search, explained with GPS navigation**

**The idea.** A* ranks each node by f(n) = g(n) + h(n):
- g(n) is the real cost already spent to reach n.
- h(n) is an estimate of the cost still left to reach the goal.

A heuristic h is **admissible** if it never overestimates the true remaining cost. For every node n, 0 <= h(n) <= h*(n), where h*(n) is the true cheapest cost from n to the goal. An admissible heuristic is always optimistic, or at worst exactly right.

**GPS analogy.** You are driving to the airport and the GPS has to choose among many possible routes.
- **g(n)** is the distance or time you have already driven to reach an intersection.
- **h(n)** is the GPS's guess for the rest of the trip. The classic guess is the straight-line ("as the crow flies") distance to the airport.
- **Why straight-line distance is admissible:** no real road can be shorter than a straight line. The actual trip is always at least that long, so the guess never overestimates.
- **Why admissibility matters:** A* stops once the goal is the cheapest item in its queue. Suppose the GPS overestimated a side street, for example calling it 20 km from the airport when it is really 8 km. A* could then write that street off and never explore it, and it would settle on a longer highway route. An optimistic guess keeps every truly good route worth checking, so the first route A* finishes with is guaranteed to be the shortest. This guarantee holds for tree search. Graph search that never reopens visited nodes also needs a consistent heuristic.
- **Trade-off:** h = 0 ("the airport could be right here") is admissible too, but it gives no guidance, and A* falls back to Dijkstra's algorithm and explores in every direction. The best heuristic stays admissible while getting as close to the true cost as possible, because tighter estimates mean fewer nodes explored.
- **Related property:** a heuristic is **consistent** (monotone) if h(n) <= cost(n, n') + h(n') for every neighbour n'. Straight-line distance is consistent because of the triangle inequality. Consistency implies admissibility.

**The question: true cost from B to G is 6, and h(B) = 5. Is h(B) admissible?**

**Yes, at node B.** Admissibility requires h(B) <= h*(B). Here 5 <= 6, so the heuristic underestimates the true remaining cost by 1. In GPS terms, it says "at least 5 km to go" when the real best route is 6 km. That is optimistic, so A* will not wrongly prune the path through B.

**Caveat:** admissibility is a property of the whole heuristic. The full heuristic is admissible only if h(n) <= h*(n) holds for every node, not just B. If h(B) had been 7, it would overestimate (7 > 6), and A* could miss the optimal path.
